# YT Download

Расширение для Edge (и Firefox): кнопка «Скачать» под плеером YouTube, выбор качества (до 4K/8K, 60 fps), MP3 и M4A, очередь загрузок с прогрессом.
Качает **yt-dlp** через маленький помощник на Node (native messaging host): сам браузер скачать YouTube не может.

## Установка (для друга)

1. Скачай репозиторий: зелёная кнопка **Code → Download ZIP**, распакуй в постоянное место (например `Документы\yt-download`). Потом папку не переноси.
2. Дважды кликни **`install.cmd`**. Если не хватает Python, Node.js или ffmpeg — он предложит поставить их через winget и поставит yt-dlp.
   Если что-то только что установилось и он просит запустить ещё раз — закрой окно и запусти снова.
3. Edge → `edge://extensions` → включи «Режим разработчика» → «Загрузить распакованное» → папка **`extension`**.
4. Полностью перезапусти Edge (и из трея тоже) — иначе он не увидит помощника.

Готово: под видео появится «Скачать». Файлы падают в `Загрузки\YouTube`, папку можно сменить в значке расширения.

## Обновления

В значке расширения есть строка **«Версия»**. Раз в 6 часов расширение само смотрит, нет ли новой версии на GitHub; если есть — появляется кнопка **«Обновить»**: она скачивает новую версию, заменяет файлы и перезапускает расширение. Ничего переустанавливать не нужно.

yt-dlp обновляется отдельно, сам, раз в день (задача планировщика `YtDownload-Update`), или кнопкой «Обновить» в строке yt-dlp.

## Как выпустить новую версию (для автора)

1. Поменяй код.
2. Подними `"version"` в `extension/manifest.json` (например 1.1.0 → 1.2.0) — по нему друзья видят, что есть обновление.
3. `git commit` и `git push` в `main`.

Если поменялся `install.ps1`, после обновления он сам перезапустится в тихом режиме.
Репозиторий, откуда берутся обновления, записан в `update.json`.

## Как устроено

- `extension/` — MV3: `background.js` (очередь, связь с хостом, проверка обновлений), `ui.js`/`ui.css` (панель для попапа и страницы), `content.js` (кнопка под видео на классах YouTube), `popup.*`.
- `host/host.js` — Node: команды от расширения, запуск `python -m yt_dlp`, прогресс, самообновление (zip с GitHub, или `git pull`, если папка — git-клон).
- ID расширения в Edge всегда `ajdmmfhbokpfeeceanpacfjfalcidddm` (ключ в manifest.json), на него завязан помощник.
- Лог помощника: `host/host.log`.

Качай для себя и уважай авторов: не перезаливай чужие видео.
