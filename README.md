# YT Download

Расширение для Microsoft Edge: под каждым видео на YouTube появляется кнопка **«Скачать»**.

- видео в любом качестве — от 144p до 4K/8K, 60 fps;
- только звук — MP3 или M4A;
- **фрагмент**: «с 1:20 по 2:05» — скачается только этот кусок, а не всё видео; из фрагмента можно сделать **GIF**;
- **плейлисты и каналы**: список видео с галочками, одно качество на все, файлы по порядку в отдельной папке;
- **обложка** видео в максимальном разрешении (наведи на превью в панели);
- **в один клик**: выбери любимое качество в значке расширения — кнопка станет «Скачать 1080p», а стрелка рядом откроет выбор. Горячая клавиша **Alt+Shift+D**;
- прогресс, скорость и оставшееся время прямо в панели, отмена в один клик;
- файлы сохраняются в `Загрузки\YouTube` (папку можно сменить).

## Установка

1. Нажми зелёную кнопку **Code → Download ZIP** и распакуй архив в постоянное место, например в `Документы\yt-download`. Потом папку не переноси.
2. Дважды кликни **`install.cmd`**. Если на компьютере не хватает нужных программ (Python, Node.js, ffmpeg), он предложит поставить их сам — соглашайся.
   Если после установки он попросит запустить его ещё раз — закрой окно и запусти снова.
3. Открой в Edge `edge://extensions`, включи **«Режим разработчика»** (слева внизу), нажми **«Загрузить распакованное»** и выбери папку **`extension`**.
4. Полностью закрой Edge (если его значок есть в трее у часов — там тоже «Закрыть») и открой снова.

Готово — открой любое видео, кнопка «Скачать» будет рядом с «Поделиться».

## Обновления

Ставить заново ничего не нужно. Когда выйдет новая версия, в значке расширения в строке **«Версия»** появится кнопка **«Обновить»** — нажми её, и расширение обновится само.

## Если что-то не работает

- **«Браузер не нашёл помощника»** — запусти `install.cmd` ещё раз и полностью перезапусти Edge.
- **Видео перестали скачиваться (ошибка 403)** — в значке расширения нажми «Обновить» в строке yt-dlp.
- **Видео 18+ или «подтвердите, что вы не бот»** — такие видео качаются только со входом в аккаунт. Расширение берёт вход из Firefox: если он у тебя есть, войди в YouTube в нём.

Скачивай для себя и не перезаливай чужие видео.
